# MLOps Labs: Відстеження експериментів (MLflow) та Версіонування даних (DVC)

Цей репозиторій містить виконання Лабораторних робіт №1 та №2. Проєкт демонструє налаштування професійного середовища MLOps, управління експериментами за допомогою MLflow та версіонування даних і пайплайнів за допомогою DVC.

## 🎯 Мета проєкту
* Організація структурованого робочого простору (спрощений Cookiecutter Data Science).
* Відстеження ML-експериментів, параметрів та артефактів за допомогою MLflow.
* Розділення версіонування коду (Git) та великих файлів даних (DVC).
* Створення відтворюваного ML-пайплайну (DAG), що складається з етапів підготовки даних та навчання моделі.

## 🚀 Відтворення пайплайну

Завдяки DVC весь процес від очистки даних до навчання моделі зведено до однієї команди. Пайплайн автоматично визначає, які кроки потрібно перезапустити, якщо змінилися вхідні дані або код, а які можна взяти з кешу.

**1. Встановлення залежностей:**
```bash
pip install -r requirements.txt
```

**2. Завантаження даних із віддаленого сховища:**
```bash
dvc pull
```

**3. Запуск пайплайну (Prepare -> Train):**
```bash
dvc repro
```

**4. Перегляд результатів експериментів:**
```bash
mlflow ui --backend-store-uri sqlite:///mlflow.db
```

## 📊 Аналіз результатів

* **MLflow:** Під час експериментів з гіперпараметром `max_depth` для `RandomForestClassifier` було зафіксовано точку оптимуму при `max_depth = 10` (найвища здатність до узагальнення, `acc_test` = 0.814). При збільшенні глибини (15, 25) спостерігалося перенавчання (Overfitting).
* **DVC:** Проєкт успішно демонструє механізм кешування. При зміні скрипта `prepare.py`, DVC автоматично виконує стадію підготовки, але пропускає стадію навчання, якщо вихідні дані не змінилися, що суттєво економить обчислювальні ресурси.
